# Superset-Sales-Dashboard( Interactive dashboard using Power BI)
## Project Objective
To contribute to the success of a business by utilizing data analysis techniques, specially focusing on time series analysis, to provide valuable insights and accurate sales forecasting.

 ## Description
 1. Dashboard Creation: Identifying KPIs, designing intuitive dashboards, and enabling data exploration.

2.  Data Analysis: Deriving insights from visualizations and charts.

3.  Sales Forecasting: Using historical data and time series for 15-day sales predictions.

4.  Actionable Insights and Recommendations: Providing strategic, actionable outputs to improve business decisions.
